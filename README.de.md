## ✨ Funktionen

- 🚀 **Eine Liste für alle Konten:** Wendet deine Sperrliste auf alle Nextcloud-Mailkonten und deine eigenen IMAP-Postfächer an.
- 🧩 **Auch bei externen Anbietern:** Schützt auch Postfächer bei Gmail, web.de und anderen, die dein Mailserver nie zu sehen bekommt.
- ⚙️ **Läuft von selbst:** Prüft die Postfächer regelmäßig im Hintergrund.
- 🔒 **Papierkorb statt Löschen:** Treffer wandern in den Papierkorb. Nichts wird endgültig gelöscht.
- 📂 **Nachvollziehbar:** Merkt sich für jede verschobene Mail, aus welchem Konto sie stammt.
- ⚡ **Sperren auf dem Server:** Mit eigenem Mailserver kann Mail Guard Domains per SSH auch direkt dort sperren.
- 🎨 **Einträge aus GLX Mail:** Absender per Rechtsklick im Spam-Ordner von GLX Mail sperren.
- 🌍 **Abgleich mit GLX Spam Guard:** Das Windows-Gegenstück nutzt dieselbe Liste. Sperren und Freigaben werden in beide Richtungen abgeglichen.
- 🛠️ **Kein Raten:** Keine Bewertung, kein Lernen: Verschoben wird nur, was ein Mensch auf die Liste gesetzt hat.
- 📊 **Open Source:** Nextcloud-App unter AGPL, für Nextcloud 30 bis 34.
